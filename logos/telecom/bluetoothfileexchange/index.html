Логотип Bluetooth File Exchange

Bluetooth File Exchange — утилита macOS от Apple для беспроводной передачи файлов между Mac и Bluetooth‑устройствами. Поддерживает протоколы OBEX и FTP‑профили Bluetooth — один из немногих способов передать файл на устройство без Wi-Fi и кабеля.
