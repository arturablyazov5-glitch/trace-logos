# Инструкции для агентов

Единственный источник правды по проекту — [CLAUDE.md](CLAUDE.md). Прочитай его целиком перед любой правкой: архитектура, формат данных, сборка, деплой. Этот файл намеренно не дублирует его — копия уже один раз молча устарела.

Три правила, без которых нельзя начинать:

1. **Сборка — только `npm run build`.** Отдельные `scripts/build-*.js` руками не запускать, сгенерированные `logos/<cat>/<slug>/index.html` не править.
2. **Публикация — `git push arturablyazov5 main` (GitHub Pages), и только через hold будущих постов** (`scripts/publish-scheduled-posts.js status` → `--force` → commit → push → `restore`). Vercel не используется. Подробности — в разделе «Hosting & deploy» в CLAUDE.md.
3. **Правила текста статей блога — в скилле `article-writing`** (`.claude/skills/article-writing/`); статьи из списка в памяти «не трогать» правятся только с явного разрешения пользователя.
