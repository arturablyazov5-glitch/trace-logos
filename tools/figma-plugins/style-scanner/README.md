# Style Scanner — Figma-плагин Trace Logo's

Figma-плагин: сканирует текущее выделение (рекурсивно по потомкам) и находит
узлы, у которых стиль или переменная подключены из **внешней библиотеки** —
то есть не определены в этом файле. Полезно перед публикацией/передачей
файла, когда нужно понять, что «утечёт» вместе с ним и на что он останется
завязан после отключения библиотеки.

Без сборки: `code.js` — рабочий файл, Figma грузит его как есть
(`manifest.json`'s `"main"`), отдельного `code.ts`/тулчейна нет — тот же
подход, что в `clean-layers`/`photo-editor`.

## Что проверяется

Шесть полей на каждом узле дерева:

| Категория | Поле узла         | Тип стиля |
|---|---|---|
| Цвет      | `fillStyleId`     | `PAINT` |
| Обводка   | `strokeStyleId`   | `PAINT` |
| Текст     | `textStyleId`     | `TEXT` |
| Эффект    | `effectStyleId`   | `EFFECT` |
| Сетка     | `gridStyleId`     | `GRID` |
| Токен     | `boundVariables`  | любая переменная |

Стиль или переменная считаются внешними, если `style.remote === true` /
`variable.remote === true`. `figma.mixed` (смешанные стили на одном узле)
пропускается — там нет одного `styleId`, который можно проверить.

## Область действия

Только явное выделение, как в `clean-layers` — без выделения плагину
нечего сканировать, сканировать всю страницу по умолчанию не начинаем
(слишком неожиданно на тяжёлом файле).

## UI

**Два экрана, как в `clean-layers`/`photo-editor`:**

1. **Ничего не выделено** — пустой стейт с подсказкой.
2. **Есть выделение** — карточка области действия, баннер результата,
   `.tool-row` «Найти внешние стили и токены» и (после скана) секция
   находок. Всё в одном экране: отдельных состояний «сканирую» и
   «результаты» нет.

Прогресс скана живёт внутри самой кнопки — спиннер вместо иконки плюс
тонкая полоска по нижней кромке `.tool-row` (обновляется каждые 40 узлов).
Итог — в баннере: `warn` с разбивкой по категориям, если что-то нашлось,
`success`, если чисто.

Список находок: фильтры-чипы по категориям (строка прячется, если
категория одна), строка на узел с хлебными крошками и тегами имён стилей,
клик — выделяет узел и ведёт к нему камеру, ↑↓/Enter — навигация с
клавиатуры. Смена выделения обнуляет прошлый результат, но переход по
клику на находку — нет: он сам меняет `figma.currentPage.selection` и
иначе схлопывал бы список после первого же перехода (см. `focusingNode`
в `ui.html`).

## Протокол сообщений

UI → sandbox: `scan`, `focus {nodeId}`, `resize {height}`, `open-url {url}`
(ссылки промо-блока — `<a target="_blank">` из iframe плагина никуда не
ведут, открывает только `figma.openExternal`).

Sandbox → UI: `selection-info {hasSelection, count, name}`,
`scanning {total}`, `progress {scanned, total, percent}`,
`results {issues, summary, scannedCount}`, `error {message}`.

## Промо-блок

Блок Trace Logo's в конце экрана результатов запекается скриптом
`node scripts/build-figma-promo.js` из `_shared/promo-banner.html` — не
редактировать между `<!-- PROMO:START -->`/`<!-- PROMO:END -->` руками,
следующий прогон затрёт.
