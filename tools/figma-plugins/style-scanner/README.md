# Style Scanner — поиск внешних стилей и переменных в Figma

## Для чего

Style Scanner помогает проверить связи с внешними библиотеками перед передачей файла заказчику или публикацией шаблона. Он пригодится дизайнеру, который переносит компоненты между проектами, и команде, которая проверяет состав своей дизайн-системы. Внешними считаются стили и переменные из библиотеки, не определённые в текущем файле.

## Что умеет

- Проверяет выделенные слои и всех их потомков.
- Находит внешние стили заливки, обводки, текста, эффектов и сеток.
- Проверяет привязанные переменные — например, в цвете, радиусе и расстоянии между элементами.
- Показывает прогресс, число проверенных слоёв и сводку находок по категориям.
- Выводит имена найденных стилей и переменных, названия слоёв и пути к ним.
- Фильтрует находки по категориям, если их несколько.
- Выделяет найденный слой и подводит к нему камеру по клику. В списке доступны клавиши ↑↓ и Enter.

## Как это работает

1. Выделите фрейм, группу или несколько слоёв в файле Figma.
2. Откройте плагин и нажмите «Найти внешние стили и токены».
3. Дождитесь проверки. Появится список находок или сообщение «Внешних стилей и токенов не найдено».
4. Нажмите на находку, чтобы перейти к слою. При необходимости замените или отвяжите его стиль либо переменную средствами Figma.

Сканирование не меняет содержимое макета. Переход к находке меняет только выделение и положение камеры, поэтому отменять скан через Undo не нужно. Чтобы продолжить работу, выберите нужные объекты на холсте.

При обычной смене выделения предыдущий результат очищается: для новой области запустите проверку заново. Переход по находкам сохраняет список.

## Установка

Работает в **Figma Design** (`editorType: ["figma"]`); FigJam не поддерживается. Для установки используйте Figma Desktop.

1. Скачайте архив плагина со страницы продукта и распакуйте его.
2. В Figma Desktop откройте **Plugins → Development → Import plugin from manifest…**.
3. Выберите `manifest.json` внутри распакованной папки.
4. Запустите плагин через **Plugins → Development → Style Scanner | Trace Logo's**.

## Ограничения и приватность

- Без выделения проверка не запускается. Весь файл автоматически не сканируется.
- Стили со смешанным значением (`figma.mixed`) и недоступные стили или переменные пропускаются. Пустой результат не гарантирует отсутствия всех зависимостей файла.
- Плагин не заменяет и не отвязывает стили или переменные. Он не проверяет все виды зависимостей, например связи с библиотечными компонентами.
- В манифесте указано `networkAccess: {"allowedDomains": ["none"]}`. Плагин не имеет сетевого доступа; данные макета не покидают Figma через сканер. Кнопки внешних ссылок открывают страницы в браузере без передачи содержимого макета.

## Для разработчиков

`code.js` — рабочий файл логики, `ui.html` — интерфейс; Figma загружает их по `manifest.json` без отдельной сборки.

Промоблок в `ui.html` между `<!-- PROMO:START -->` и `<!-- PROMO:END -->` генерируется из `../_shared/promo-banner.html` скриптом `scripts/build-figma-promo.js` при общей сборке проекта (`npm run build`). Не редактируйте этот блок вручную.
