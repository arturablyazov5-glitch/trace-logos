# Clean Layers — Figma-плагин для удаления скрытых слоёв и лишнего оформления

## Для чего

Clean Layers помогает убрать скрытые черновики и выключенные заливки, обводки и эффекты из выбранной части макета. Подойдёт дизайнеру после нескольких итераций или перед передачей файла коллегам. Область чистки задаётся выделением — весь файл автоматически не обрабатывается.

## Что умеет

- Удалять скрытые фреймы, группы, векторы, текст и другие узлы вместе с их содержимым, включая вложенные слои выделения.
- Убирать выключенные заливки, обводки и эффекты у видимых узлов, сохраняя сами узлы.
- Удалять заливки под полностью непрозрачной заливкой: сплошным цветом или градиентом, у которого все точки непрозрачны.
- Показывать количество доступного для чистки до запуска и результат после операции.

Два инструмента независимы: можно использовать любой из них отдельно или запускать оба в любом порядке.

## Как это работает

1. Выделите нужные объекты на холсте: отдельный слой, группу или фрейм. Плагин проверит выделение и его потомков.
2. Посмотрите найденное в карточке выделения. Если инструменту нечего чистить, его кнопка недоступна.
3. Нажмите «Удалить скрытые слои» или «Удалить скрытые заливки, обводки, эффекты».
4. Проверьте результат: первая кнопка удаляет узлы целиком; вторая меняет только массивы заливок, обводок и эффектов у видимых узлов. После операции счётчики обновляются.

Для отмены используйте обычную историю Figma: **Cmd+Z** на macOS или **Ctrl+Z** на Windows. Собственной истории изменений у плагина нет.

## Установка

1. Скачайте архив плагина со страницы продукта и распакуйте его.
2. Откройте **Figma Desktop → Plugins → Development → Import plugin from manifest…**.
3. Выберите `manifest.json` внутри распакованной папки.
4. В нужном документе выделите объекты и запустите **Plugins → Development → Clean Layers | Trace Logo's**.

В манифесте указаны редакторы **Figma, FigJam, Slides и Buzz** (`editorType`: `figma`, `figjam`, `slides`, `buzz`). Чистка оформления применяется к свойствам, которые поддерживает выбранный тип узла.

## Ограничения и приватность

- Без выделения чистка недоступна. Для обработки всей текущей страницы сначала выделите на ней нужные объекты.
- Скрытые узлы внутри инстансов компонентов не удаляются. Сам скрытый инстанс может быть удалён целиком; автоматически отсоединять инстансы плагин не умеет.
- **Блокировка не защищает от чистки.** Скрытые мастер-компоненты и наборы компонентов тоже удаляются — это может нарушить связь с инстансами. Проверяйте выделение перед запуском.
- Нулевая непрозрачность (`opacity: 0`) сама по себе не считается скрытой видимостью и не служит причиной удаления узла.
- Изображения, видео, прозрачные градиенты и заливки с режимами смешивания вроде Multiply или Screen не считаются непрозрачным перекрытием. Правило перекрытия относится только к заливкам, а не к обводкам и эффектам.
- Плагин не измеряет размер файла или экономию памяти.

Фактическое значение в манифесте: `networkAccess: { "allowedDomains": ["none"] }`. Сетевые запросы плагину запрещены. Обработка выполняется внутри Figma: содержимое макета не покидает Figma и не отправляется на сервер плагина.

## Для разработчиков

`code.js` — рабочая точка входа из `manifest.json`, отдельная компиляция не требуется; интерфейс находится в `ui.html`. Блок между `<!-- PROMO:START -->` и `<!-- PROMO:END -->` в `ui.html` генерируется из `tools/figma-plugins/_shared/promo-banner.html` при общей сборке `npm run build` — вручную его не правят.
