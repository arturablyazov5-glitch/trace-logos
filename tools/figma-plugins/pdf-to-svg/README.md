# PDF → Figma — импорт страниц PDF в отдельные фреймы

## Для чего

Плагин переносит PDF на холст Figma для дальнейшей работы с макетом. Подходит дизайнерам, которым нужно разобрать векторную схему, чертёж или презентацию, либо использовать страницу как изображение. Исходный PDF остаётся без изменений.

## Что умеет

- Принимать PDF через выбор файла или перетаскивание в панель.
- Импортировать все страницы или выбранные номера и диапазоны, например `1-3, 7`.
- В режиме **«Вектор»** создавать редактируемые контуры, заливки и обводки; переводить надписи в кривые, когда доступны данные встроенного шрифта.
- В режиме **«Картинка»** помещать страницу как PNG-заливку отдельного фрейма. Плотность — от 1× до 4×, по умолчанию 2×; размер фрейма от плотности не зависит.
- Показывать прогресс, предупреждения и число импортированных или пропущенных страниц.

## Как это работает

1. Запустите плагин. Выделять объекты на холсте не нужно.
2. Перетащите PDF в панель или нажмите на область загрузки и выберите файл.
3. Выберите **«Вектор»** или **«Картинка»**. Укажите страницы; пустое поле означает все страницы. Для картинки выберите плотность.
4. Нажмите **«Конвертировать»**. Плагин добавляет страницы по одной на текущую страницу Figma: слева направо, начиная от центра текущего вида холста.
5. По завершении новые фреймы выделяются, и Figma показывает их на холсте. Имена содержат название PDF и номер страницы. Существующие слои не меняются.

**«Отмена»** останавливает дальнейший импорт после обработки текущей страницы; уже добавленные фреймы остаются. Чтобы убрать результат, удалите выделенные импортированные фреймы или используйте обычную отмену действий Figma (`Cmd+Z` / `Ctrl+Z`, при необходимости несколько раз).

## Установка

1. Скачайте архив со страницы продукта и распакуйте его.
2. В **Figma Desktop** откройте **Plugins → Development → Import plugin from manifest…**.
3. Выберите `manifest.json` внутри распакованной папки.
4. Запускайте через **Plugins → Development → PDF → Figma | Trace Logo's**.

В манифесте указаны редакторы **Figma Design** и **Figma Slides**: `editorType: ["figma", "slides"]`.

## Ограничения и приватность

- Плагин не распознаёт текст и не трассирует сканы: растровые вставки остаются изображениями даже в режиме «Вектор».
- Надписи, переведённые в кривые, нельзя редактировать как текст. Если контуры шрифта недоступны, часть надписей остаётся текстом; возможна подстановка шрифта.
- Векторный импорт может отличаться от PDF: мягкие маски становятся непрозрачными, отдельные заливки могут потеряться, очень тонкие линии выглядят бледнее. Некоторые CJK-шрифты без встроенных данных могут не отрисоваться. Для таких страниц используйте «Картинка».
- При ошибке сборки SVG плагин пробует импортировать страницу как PNG с плотностью 2×. Если страницу не удаётся добавить в Figma, она пропускается; результат сообщает об ошибках и заменах.
- PDF под паролем не открывается: сначала снимите защиту вне плагина. Тяжёлые страницы и высокая плотность требуют больше времени и памяти.

Фактическое значение в манифесте: `networkAccess: { "allowedDomains": ["none"] }`. PDF обрабатывается локально внутри плагина; движки встроены в панель. Плагин не отправляет документ на внешние серверы: данные остаются внутри Figma.

## Для разработчиков

`code.js` — рабочий исходник, не генерируемый файл; он создаёт узлы Figma. `ui.html` читает PDF и передаёт готовые страницы по одной, ожидая подтверждения добавления.

Движки из `vendor/` запекаются скриптом `scripts/build-figma-pdfjs.js` в блок `PDFJS:START` / `PDFJS:END` внутри `ui.html`; этот блок вручную не править. Обновление выполняется через `npm run build` из корня репозитория. Сохраните pdf.js 3.x: в 4.x удалён используемый SVG-бэкенд. Встроенный worker работает в потоке панели, без загрузки из сети.
