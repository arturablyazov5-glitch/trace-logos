# Photo Editor — плагин для обрезки, отражения и экспорта изображений в Figma

## Для чего

Photo Editor работает с изображениями, которые уже находятся в макете. Он помогает убрать прозрачные поля вокруг объекта, исправить растянутую рамку и сохранить изображения для сайта или презентации без перехода в другой редактор.

## Что умеет

- **Обрезать прозрачность** — удаляет прозрачные пиксели по краям изображения, подгоняет размер и положение слоя под содержимое.
- **Восстановить оригинал** — возвращает размер и пропорции изображения из заливки, сбрасывает поворот и скругление углов слоя.
- **Отразить по горизонтали или вертикали** — зеркально отражает пиксели изображения, сохраняя размер, положение и поворот слоя.
- **Экспорт в WebP** — сохраняет вид слоя на холсте, включая обрезку, размер, поворот и скругление. Качество фиксировано — 0.8. Один результат скачивается как `.webp`, несколько — одним ZIP-архивом; имена файлов берутся из имён слоёв.
- **Оригинал в PNG** — сохраняет исходные пиксели текущей заливки без трансформаций слоя, обрезая прозрачные поля. Доступен при выделении одного изображения.
- **Отменить / Повторить** — собственная история операций для текущего выделения, до 50 шагов.

## Как это работает

1. Выделите на текущей странице один или несколько слоёв с заливкой изображением и запустите плагин. Панель покажет подходящие изображения.
2. Нажмите нужную кнопку. Обрезка и отражение заменяют изображение в заливке; восстановление меняет параметры слоя. Обрезка и восстановление устанавливают режим заливки `FILL`.
3. Для сохранения на диск выберите «Экспорт в WebP» или «Оригинал в PNG». Экспорт не изменяет исходный слой и не добавляется в историю правок.
4. Чтобы отменить или повторить обработку, используйте кнопки плагина. При переключении на другое выделение история сбрасывается. Обычный Cmd+Z / Ctrl+Z относится к истории всего документа Figma.

Перед обрезкой, восстановлением и отражением плагин оставляет одну подходящую IMAGE-заливку, удаляет дополнительные заливки и сбрасывает её фильтры и прозрачность. Эта подготовка выполняется до снимка собственной истории и не отменяется кнопкой «Отменить» плагина.

## Установка

1. Скачайте архив плагина со страницы продукта и распакуйте его.
2. В **Figma Desktop** откройте **Plugins → Development → Import plugin from manifest…**.
3. Выберите `manifest.json` внутри распакованной папки.
4. Запустите **Plugins → Development → Photo Editor | Trace Logo's**.

В manifest заявлены редакторы **Figma Design, FigJam, Figma Slides и Figma Buzz** (`editorType: ["figma", "figjam", "slides", "buzz"]`). Для работы нужен слой с заливкой изображением; доступность операций зависит от типа слоя.

## Ограничения и приватность

- Плагин не удаляет белый или цветной фон, не ретуширует фото и не предоставляет цветокоррекцию. Обрезка убирает только прозрачные поля; у непрозрачного JPEG обрезать нечего.
- Слои со смешанными заливками или несколькими одновременно видимыми изображениями пропускаются. Группы не обходятся: выделяйте сами слои с изображениями.
- Обрезка и восстановление не сохраняют ручной кроп `CROP`: изображение заполняет весь слой в режиме `FILL`. При отражении координаты существующего кропа остаются прежними и могут показывать другой участок изображения.
- При обрезке повёрнутого слоя его положение может сместиться. Восстановление сбрасывает поворот в ноль.
- «Оригинал» — изображение из текущей заливки, а не копия до всех прошлых правок. После замены пикселей обрезкой или отражением экспорт PNG использует уже изменённую заливку.
- Если имя или размер слоя изменены вне плагина, перевыделите изображение, чтобы обновить сведения в панели.

Фактическая настройка manifest: `networkAccess: { "allowedDomains": ["none"] }`. Изображения обрабатываются внутри Figma и окна плагина, без отправки данных на внешние серверы. При экспорте файлы сохраняются на вашем устройстве; облачное хранение самого документа Figma регулируется платформой.

## Для разработчиков

- `code.js` — рабочий исходник логики без отдельной компиляции; `ui.html` содержит интерфейс и обработку изображений через canvas.
- Блок `PROMO:START/END` в `ui.html` генерируется `scripts/build-figma-promo.js` в составе `npm run build`; вручную его не править. Встроенный JSZip обновляется копированием из `js/vendor/jszip.min.js`, без правок кода библиотеки.
- Массовый экспорт сохраняйте одним ZIP: не заменяйте его серией скачиваний или `showDirectoryPicker`, недоступным в песочнице плагина.
