Правила
в 2020 году → в·2020·году
10 кг, № 5, И. И. Иванов → 10·кг, №·5, И.·И.·Иванов
· — неразрывный пробел: слова по его сторонам никогда не разъедутся по разным строкам
Логотип - лицо бренда → Логотип·— лицо бренда
2019-2020 → 2019‑2020
Перед длинным тире — неразрывный пробел, чтобы тире не осталось одно в начале строки
"Сбер" и “Яндекс” → «Сбер» и «Яндекс»
Клиент: «отлично сработали» → Клиент: «Отлично сработали»
Д'Артаньян и О'Брайен → Д’Артаньян и О’Брайен
Один уровень вложенности: кавычки внутри кавычек не различаются. После «подпись: «цитата»» первая буква цитаты — заглавная. Апостроф между двумя буквами (без пробела) — типографский, не прямая кавычка
Скоро... → Скоро…
Логотип  и  шрифт . → Логотип и шрифт.
Тур в минус🥵🥵🥵 → Тур в минус·🥵🥵🥵
· — тот же неразрывный пробел, что и в первом правиле: эмодзи не оторвётся от последнего слова при переносе строки. Ставится только один раз, перед всей серией эмодзи, а не между эмодзи внутри неё
Стоимость ( примерно ) → Стоимость (примерно)
Пробел сразу внутри скобок — квадратных и круглых — убирается с обеих сторон
- вектор → • Вектор
1. растр → 1. Растр
- сделать превью. → • Сделать превью
Маркер убирается из текста — нумерацию рисует сама Figma. Первая буква пункта — заглавная. Точка в самом конце пункта убирается — а внутри, если там несколько предложений, остаётся
После занятий родитель⏎понимает, как ребёнок⏎включается → После занятий родитель понимает, как ребёнок включается
Пустая строка (двойной перенос) и строка со списочным маркером не склеиваются — это осмысленная граница абзаца или пункта списка, а не перенос по ширине слоя
на обработку персональных данных → на обработку персональных данных
Курируемый список конкретных формулировок (не по любому падежу автоматически) — обычно это ссылка на юридический документ, даже когда самой ссылки в макете нет. Уже подчёркнутое повторно не трогается
медвежонок ищет мед → медвежёнок ищет мёд
Выключено по умолчанию — отдельное действие поверх остальной типографики, не автоматическое правило. Словарь узнаёт только слова, где «ё» обязательна по написанию, поэтому омографы вроде «все»/«всё» не трогает — их в списке нет
