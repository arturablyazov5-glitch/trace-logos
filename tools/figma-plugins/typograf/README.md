# Typograf | Trace Logo's — русская типографика в текстовых слоях Figma

## Для чего

Плагин приводит текст в макете к нормам русской типографики: ставит неразрывные пробелы, длинные тире, «ёлочки» и многоточия, убирает лишние пробелы. Нужен дизайнерам, которые собирают лендинги, карточки и презентации и не хотят править текст вручную слой за слоем.

## Что умеет

Каждое правило включается и выключается тумблером; выбор сохраняется между запусками.

- **Неразрывные пробелы** — после предлогов и союзов, перед частицами, между инициалами, между числом и единицей измерения, в разрядах чисел.
- **Тире** — дефис между словами становится длинным тире, диапазон чисел — неразрывным дефисом.
- **Кавычки-ёлочки** — прямые и «умные» кавычки заменяются на «ёлочки».
- **Многоточие** — три точки подряд превращаются в один символ «…».
- **Пробелы** — лишние убираются, перед эмодзи добавляются.
- **Списки** — дефис или цифра в начале абзаца превращаются в список Figma.
- **Склеить переносы строк** — Enter внутри абзаца заменяется пробелом, перенос по ширине делает Figma.
- **Подчёркивание согласий** — формулировки вроде «персональных данных» и «конфиденциальности» подчёркиваются.
- **Расставить ё** — по словарю однозначных слов: «елка» становится «ёлкой».

Адреса сайтов (URL) правила не затрагивают.

## Как это работает

1. Выделите на холсте текстовый слой, группу или фрейм. Плагин найдёт все текстовые слои внутри.
2. Запустите плагин, при необходимости отключите лишние правила и нажмите «Расставить типографику».
3. Плагин правит только изменившиеся фрагменты текста, поэтому оформление остального текста (шрифты, цвета, ссылки) сохраняется. Слои, которые не удалось обработать, показываются в списке «пропущено N»: оттуда можно перейти к слою и повторить попытку.
4. Результат («Изменено N из M») виден в окне плагина и в уведомлении на холсте. Остановить обработку можно кнопкой «Остановить» или клавишей Esc.

Меняется только текст выбранных слоёв. Отменить — ⌘Z (macOS) или Ctrl+Z (Windows).

## Установка

Только из архива.

1. Скачайте архив на [странице продукта](https://trace-logos.ru/tools/figma-plugins/typograf/) и распакуйте его.
2. В Figma Desktop откройте Plugins → Development → Import plugin from manifest… и выберите `manifest.json` из распакованной папки.
3. Запускайте через Plugins → Development → Typograf | Trace Logo's.

Плагин работает в Figma, FigJam и Slides (`editorType` в `manifest.json`).

## Ограничения и приватность

- Списки предлогов, частиц, единиц и словарь ёфикатора составлены вручную и не исчерпывающие.
- Вложенные кавычки не различаются: поддерживается один уровень.
- Текстовые слои длиннее 50 000 символов пропускаются.
- Плагин не лечит сам текст: не исправляет орфографию и не переписывает фразы.
- Сеть отключена (`networkAccess` в `manifest.json`: `allowedDomains: ["none"]`). Текст не покидает Figma; в `clientStorage` хранятся только положения тумблеров.

## Для разработчиков

- Блок правил в `code.js` между `// RULES:START` и `// RULES:END` запекается из `tools/figma-plugins/_shared/typograf-rules.js` скриптом `scripts/build-figma-typograf.js`; правила правятся только в источнике.
- Словарь ёфикатора между `// YO_WORDS:START` и `// YO_WORDS:END` генерируется `scripts/build-figma-yo.js` из `resources/yo.js`; руками не правится. Остальное в `code.js` и `ui.html` правится как обычный код, затем `npm run build`.
- Тесты алгоритма диффа лежат в `tests/`.
