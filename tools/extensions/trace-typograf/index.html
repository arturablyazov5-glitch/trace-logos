Перед первым запуском

Это расширение или плагин для Figma?

Расширение для Chrome: Taptop и Tilda. Версия для Figma — отдельный продукт.

Где работает расширение?

В редакторе Taptop и редактируемых полях на поддоменах tilda.cc. Другие площадки не заявлены.

Сохраняется ли оформление?

Правки применяются точечно. Ручные переносы могут склеиваться; проверьте результат перед публикацией.

Почему ничего не происходит?

Перезагрузите редактор. Выберите слой в Taptop или кликните в текстовое поле Tilda.

Есть ли установка из Chrome Web Store?

В README описан режим разработчика. Ссылки на Web Store и готовую загрузку здесь нет.
