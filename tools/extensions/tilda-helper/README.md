# Tilda Helper

Расширение для Chrome (Manifest V3) с несколькими фичами для редактора Tilda:

- **Бейдж ID/класса блока** — показывает ID блока (`#rec…`) рядом с кнопками
  «Настройки» и «Редактировать блок» при наведении на блок. Клик по ID
  копирует его в буфер обмена (на 1,2 сек появляется надпись «Скопировано»).
- **Z-index** — поле в сайдбаре «Настройки» блока для управления z-index
  без ручной правки кода.
- **Мультипревью** — 3 вьюпорта (мобильный/планшет/десктоп) рядом с
  синхронным скроллом, для проверки адаптива на опубликованной странице.
- **Автовключение продвинутого режима** — на страницах списка сайтов и
  списка страниц сайта (`/projects/…`) сразу включает компактную таблицу
  вместо крупных превью-плиток, не дожидаясь родного порога Tilda (когда
  элементов больше 15).

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать эту папку (`tilda-helper/`).
3. Перезагрузить вкладку с редактором Tilda.

## Разработка и сборка

Исходники разбиты по фичам в `src/`, а Chrome грузит один собранный файл
`content.js` (в `manifest.json` — `world: "MAIN"`). Правим `src/`, затем
пересобираем:

```
npm run build      # разовая сборка src/index.js → content.js
npm run watch      # пересборка на каждое сохранение
```

Раскладка `src/`:

| Файл             | Назначение                                                       |
| ---------------- | ----------------------------------------------------------------|
| `index.js`       | точка входа: маршрутизация по URL, инъекция стилей, `tick()`, интервал |
| `badges.js`      | фича бейджей ID/класса блока + иконочная верхняя панель          |
| `zindex.js`      | фича Z-index (T123-carrier, сохранение, reorder, поле сайдбара)  |
| `multipreview.js`| фича мультипревью (3 viewport'а, синхроскролл на published-странице) |
| `powermode.js`   | автовключение продвинутого режима на `/projects/…`               |
| `dom.js`         | общие DOM-хелперы (`getAllRecs`, `getRecordWrapper`, …)          |
| `styles.js`      | единый `<style>` расширения                                     |
| `icons.js`       | SVG-иконки                                                       |
| `constants.js`   | общие имена классов, маркеры, тексты                            |

`content.js.bak` — прежний монолитный файл до разбивки (бэкап, в Chrome не нужен).

## Как это работает

- Блоки страницы в редакторе — `div.r.t-rec` с `id="recXXXXXXXXXX"`.
- Панели кнопок (`.tp-record-ui`) лежат отдельно от блоков и не содержат
  ссылки на ID — сопоставление делается по совпадению вертикальной позиции
  (top панели == top блока).
- Панели пересоздаются редактором при добавлении/удалении/перемещении блоков,
  поэтому бейджи поддерживаются периодическим проходом каждые 700 мс
  (проход идемпотентный, дубликатов не создаёт).
- Бейдж оформлен как родная кнопка Tilda (`.tp-record-ui__button`), поэтому
  показывается/скрывается вместе с остальными кнопками при наведении.

После правок кода: `chrome://extensions` → ⟳ у расширения → перезагрузить
вкладку редактора.
