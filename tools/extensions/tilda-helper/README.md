# Tilda Helper — расширение для редактора Tilda

Chrome-расширение, которое добавляет в редактор Tilda недостающие мелочи: ID блока одним кликом, Z-index без правки кода, мультипревью адаптива и копирование кода T123.

## Для чего

Tilda Helper нужен тем, кто собирает сайты в Tilda и часто лезет в настройки блоков за ID, CSS-классом или Z-index, а адаптив проверяет по очереди на разных экранах. Расширение выносит эти действия прямо в интерфейс редактора. Это независимое расширение, не официальный продукт Tilda.

## Что умеет

- **ID и CSS-класс блока.** При наведении на блок рядом с кнопками «Настройки» и «Редактировать блок» появляется бейдж с ID вида `#rec845210`. Клик копирует его в буфер обмена.
- **Z-index.** В настройках блока появляется поле Z-index. Значение сохраняется в служебном блоке T123 под ним, править код вручную не нужно. В редакторе изменение видно сразу.
- **Атрибуты.** Кнопка «Добавить атрибут» в настройках блока добавляет произвольный атрибут к блоку через служебный T123.
- **Мультипревью.** Три окна рядом (десктоп 1201 px, планшет, телефон) с синхронной прокруткой — для проверки адаптива на опубликованной странице.
- **Копирование кода T123.** Кнопка «Скопировать» у превью кода в блоке T123.
- **Копирование якоря.** Кнопка у блока якорной ссылки кладёт в буфер имя якоря сразу в формате `#имя`.
- **Списки проектов и страниц.** На страницах `/projects/…` сразу включается компактная таблица вместо крупных плиток.
- **Хлебные крошки.** В шапке редактора достраиваются страницы-предки вложенной страницы.
- **Zero Block.** В редакторе Zero Block автоматически открывается панель настроек.

## Как это работает

1. Откройте редактор Tilda — расширение подключается к странице само, ничего нажимать не нужно.
2. Наведите курсор на блок: появятся ID и другие кнопки. Нажмите нужную.
3. Для Z-index введите значение в поле настроек блока и сохраните страницу. Расширение создаст под блоком служебный блок T123 с CSS; он остаётся в проекте, как любой другой блок.
4. Для мультипревью сначала сохраните и опубликуйте страницу: превью открывает именно опубликованную версию на `tilda.ws`. После правок опубликуйте заново и откройте мультипревью снова.

Чтобы отменить: удалите блок T123 со Z-index или атрибутами. Если отключить расширение, кнопки исчезнут после перезагрузки редактора, а уже сохранённый код Z-index и атрибутов останется в проекте.

## Установка

1. Скачайте архив и распакуйте его.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку (ту, где лежит `manifest.json`).
4. Перезагрузите вкладку с редактором Tilda.

Подходят браузеры на Chromium: Chrome, Edge, Яндекс Браузер. Расширение работает в редакторах страниц и проектов на `tilda.ru` и `tilda.cc`, в редакторе Zero Block, а мультипревью — на опубликованных страницах `*.tilda.ws`.

## Ограничения и приватность

- Z-index и атрибуты не действуют для блоков, у которых Tilda не поддерживает служебный T123 (например, T1093).
- Мультипревью показывает только опубликованную версию страницы.
- Запрашивается одно разрешение, `clipboardWrite`, — для копирования ID, классов, якорей и кода в буфер обмена. Остальным браузерным API расширение не пользуется.
- Расширение работает только на страницах Tilda из списка выше. Запросы идут на сам сайт Tilda (тот же домен, с вашей сессией) — например, чтобы сохранить Z-index и построить хлебные крошки. Собственного сервера у расширения нет, ваши данные никуда не отправляются.

## Для разработчиков

Chrome загружает один собранный файл `content.js`; исходники лежат в `src/` (точка входа `src/index.js`, по файлу на функцию). `content.js` — артефакт сборки, руками его не правят.

```
npm install
npm run build   # src/index.js → content.js (esbuild)
npm run watch   # пересборка при сохранении
```

После правок: `chrome://extensions` → ⟳ у расширения → перезагрузить вкладку редактора.

Страница продукта: https://trace-logos.ru/tools/extensions/tilda-helper/
