# Taptop Helper — расширение для редактора Taptop

Chrome-расширение для редактора Taptop: выделение нескольких слоёв, копирование и вставка между страницами, удаление и публикация всех страниц одной кнопкой.

## Для чего

В Taptop слои переносят по одному, а каждую страницу публикуют отдельно. Taptop Helper добавляет групповые действия: он нужен, когда надо перенести шапку, подвал и несколько блоков на другую страницу или опубликовать весь сайт после правок. Это независимое расширение, не официальный продукт Taptop.

## Что умеет

- **Мультивыбор слоёв** — Cmd+клик на Mac или Ctrl+клик на Windows по слоям.
- **Копирование и вставка между страницами** — Cmd/Ctrl + C и Cmd/Ctrl + V. Буфер сохраняется при переходе между страницами.
- **Удаление выделенных слоёв** — клавишей Delete или Backspace.
- **«Опубликовать всё»** — кнопка в шапке редактора, публикует страницы сайта по очереди и показывает прогресс.
- **Режим «Дизайнер» по умолчанию** — при заходе в редактор расширение один раз включает этот режим.
- **«Сжать фото»** — кнопка в панели картинки: расширение подбирает качество WebP и заменяет изображение более лёгким.

## Как это работает

1. Откройте редактор Taptop (адрес вида `…/-/cms/v1/mosaic/…`) — расширение подключается к странице само.
2. Выделите слои с зажатым Cmd/Ctrl и нажмите Cmd/Ctrl + C. Уведомление покажет, сколько слоёв в буфере.
3. Перейдите на другую страницу и нажмите Cmd/Ctrl + V — слои вставятся.
4. Для публикации нажмите «Опубликовать всё» в шапке режимов «Дизайнер» и «Наполнение» (в режиме «Просмотр» кнопка скрыта) и дождитесь конца в открытой вкладке.

Буфер очищают перезагрузка страницы и Escape; переход между страницами его не очищает. Удаление и публикация выполняются через сам редактор Taptop, поэтому отменять их нужно средствами Taptop.

## Установка

1. Скачайте архив и распакуйте его.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку (ту, где лежит `manifest.json`).
4. Перезагрузите вкладку с редактором Taptop.

Подходят браузеры на Chromium: Chrome, Edge, Яндекс Браузер. Расширение работает на страницах редактора, чей адрес содержит `/-/cms/v1/mosaic/`. Иконка расширения открывает окно со статусом: активно ли расширение, сколько слоёв выбрано и кнопка публикации.

## Ограничения и приватность

- Во время публикации вкладку закрывать нельзя: процесс идёт в ней.
- Нужны аккаунт Taptop и доступ к проекту; отдельного аккаунта у расширения нет.
- Расширение использует внутренние механизмы страницы редактора, поэтому после обновления Taptop отдельные функции могут временно перестать работать.
- Разрешения: `activeTab`, `scripting` и `tabs` — чтобы окно расширения видело текущую вкладку и запускало публикацию; доступ к страницам вида `*://*/-/cms/v1/mosaic/*` — единственные адреса, где работает расширение.
- Своего сервера у расширения нет, содержимое проектов никуда не отправляется. Единственный сетевой запрос — загрузка исходной картинки при «Сжать фото», она идёт на сам сайт проекта.

## Для разработчиков

Сборки нет: `content.js` подключён с `"world": "MAIN"` (нужен доступ к внутреннему API редактора), поэтому `chrome.runtime.getURL()` в нём недоступен — картинки промо вшиты в `promo-assets.js` как `data:`-URI. `background.js` хранит состояние публикации, `popup.html`/`popup.js` — окно расширения.
