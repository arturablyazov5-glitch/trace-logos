# Taptop Block IDs

Клик по иконке расширения — включает/выключает показ ID каждой секции (блока верхнего уровня) Taptop, например `i3bdp5ptg_0`. Плашка прилипает к верху окна, клик копирует `#ID`, наведение подсвечивает секцию.

Установка: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → эта папка.
