Photo Editor FAQ

How do I trim transparent margins from an image in Figma?

Select a layer with an image, run the plugin and click “Trim transparency”: empty pixels at the edges are removed and the layer resizes to fit the content. The plugin does not remove white backgrounds. Before editing, it keeps a single image fill and resets filters and opacity.

How do I restore an image’s original proportions in Figma?

“Restore original” takes the size and proportions from the fill itself and resets rotation and corner radius. It’s handy when an image has been stretched by accident.

How do I flip an image horizontally or vertically in Figma?

Each direction has its own button. The plugin mirrors the image pixels, while the layer’s size, position and rotation stay the same.

How do I export an image from Figma as WebP?

Click “Export WebP”: the file matches the layer as it looks on the canvas, including crop, size, rotation and corner radius. Quality is fixed at 0.8. Several layers download as one ZIP archive. To learn why the format suits websites, read “What is WebP”.

Can I export the original image as PNG?

Yes. “Original as PNG” saves the fill’s original pixels without the layer’s transformations and trims transparent margins. It works when a single image is selected.

Can I undo the plugin’s changes?

Yes. The plugin keeps its own 50-step history with Undo and Redo buttons. Selecting something else resets it.

Are my images sent to a server?

No. Images are processed inside Figma and the plugin window, and network access is disabled in the manifest. To compress images without Figma, try the online tool “Compress image”.

How do I install Photo Editor and how much does it cost?

The plugin is free; pay what you want. Download and unzip the archive, then in Figma Desktop choose Plugins → Development → Import plugin from manifest… and select manifest.json. More plugins and tools live in the “Tools”.
