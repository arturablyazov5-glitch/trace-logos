Всё содержимое базы знаний — обычные markdown-файлы в `kb/articles/`. Структура папок и есть дерево:

- **папка** = раздел. Может содержать вложенные папки (подразделы) и `.md` файлы (статьи), в любом сочетании и на любую глубину.
- **`.md` файл** = статья. Начинается с frontmatter (`title` обязателен, `excerpt`/`icon`/`order` — опционально), дальше обычный markdown.
- **`_section.json`** (необязательный, лежит внутри папки-раздела) — задаёт `title`/`icon`/`order` для раздела. Без него заголовок берётся из имени папки, а порядок — алфавитный.

## Пример

```
kb/articles/
  design/
    _section.json          → { "title": "Дизайн", "icon": "🎨" }
    logotipy/
      _section.json        → { "title": "Логотипы" }
      seo-2026.md
    palitra.md
```

Такая структура даст раздел «Дизайн», внутри — подраздел «Логотипы» со статьёй «seo-2026», и статью «palitra» прямо в «Дизайн».

После правки файлов запусти:

```
node scripts/build-kb.js
```

:::note
`id` статьи/раздела — это имя файла или папки без расширения. Он должен быть уникален по всему дереву: на нём строится прямая ссылка вида `#/seo-2026`. Сборка упадёт с понятной ошибкой, если два узла назвать одинаково.
:::
