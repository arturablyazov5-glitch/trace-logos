Got questions?

How do I find external library styles and variables in Figma?

Select a frame or group and click “Find external styles and tokens”. The plugin checks the selected layers and their descendants: fills, strokes, text, effects, grids and bound variables from external libraries.

Does it change my design?

No. The plugin only finds links. Jumping to a result changes the selection and the camera position.

How do I jump to a found layer?

Click a result in the list: the plugin selects the layer and moves the camera to it. Use ↑↓ and Enter to walk the list, and filter results by category.

Does an empty result mean the file is independent?

No. Mixed styles and inaccessible links are skipped. The check does not cover every dependency of the file.

Where does my design go?

The plugin has no network access: allowedDomains is none. Yandex Metrica analytics runs on this page.

How do I install the plugin?

In Figma Desktop: Plugins → Development → Import plugin from manifest… → pick manifest.json in the unzipped folder. The plugin works in Figma Design; FigJam is not supported.

What should I do with the styles it finds before handing the file off?

Replace or detach them with Figma’s own tools. While you are at it, clear out hidden drafts with Clean Layers: it deletes hidden layers and leftover styling.

How much does the Style Scanner plugin cost?

Free to download: pay what you want, even $0. No sign-up needed.
