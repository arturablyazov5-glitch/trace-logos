How do I delete all hidden layers in Figma at once?

Select a frame or group, run Clean Layers and click “Delete hidden layers”. Hidden nodes disappear together with their contents, nested ones included.

How do I remove hidden fills, strokes and effects?

The “Delete hidden fills, strokes, effects” button cleans disabled entries on visible nodes and leaves the layers themselves. Fills under a fully opaque fill are removed too. The two tools are independent: run either one on its own, or both in any order.

How do I set the scope, and where does my file go?

Select the layers you want cleaned: without a selection the cleanup is unavailable. The plugin has no network access; everything runs inside Figma.

Does locking protect layers and main components?

No. Hidden locked nodes and main components are deleted; deleting a main component can break the link to its instances.

What is left after the layer cleanup?

Layers with opacity 0% and hidden nodes inside instances. A hidden instance itself is deleted whole; there is no automatic Detach.

How do I undo the result?

With the regular Figma undo: Cmd+Z / Ctrl+Z. The plugin has no history of its own.

What should I check before handing a file off to developers?

After the cleanup, look for links to external libraries with Style Scanner: it shows the external styles and variables in your selection.

How much does the Clean Layers plugin cost?

Free to download: pay what you want, even $0. No sign-up needed.
