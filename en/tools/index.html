How files are processed

Image compression, PDF merging, cropping and watermark removal run in your browser. Selected files are not uploaded to a processing server. An internet connection is needed to load the page and libraries. The Figma catalogue downloads logos from the site, while extensions work with pages open in their respective services.

Frequently asked questions

Which tools are free to use?

The web utilities are free and require no signup. You can download Reviews Exporter for free or support development during download. For plugins and extensions marked Access from the author, contact the author on Telegram; each card explains how to get access.

How do Figma plugins, extensions and online utilities differ?

A plugin works with selected elements in Figma. An extension adds commands to Tilda, Taptop or a review platform. An online utility opens in a browser and processes a selected file without installation.

How do I compress an image for a website?

Open the WebP and SVG tool, add images and check the preview. For photos, you can adjust quality and download several files in an archive. SVG optimization preserves the vector format.

Does merging PDFs preserve their quality?

Without compression, pages are copied into the resulting document. The optional compression mode converts pages to JPEG images, so small text and fine lines may become less sharp.

Can I edit text after importing a PDF into Figma?

PDF → Figma converts text to outlines in vector mode. You can edit paths, but cannot change words as you would in a text layer. Raster mode inserts each page as an image.

Which reviews does Reviews Exporter collect?

Business reviews on Yandex Maps, seller and residential building reviews on Avito, product reviews on Ozon, and post comments in Telegram Web. Results are saved to Markdown. Export completeness depends on available entries and sign-in requirements.

How do I install an extension in Chrome?

Download an archive from the author or extension page, unzip it, open chrome://extensions and enable Developer mode. Click Load unpacked and select the folder containing manifest.json. Step-by-step instructions are above.

Can I install the extensions in Yandex Browser or Edge?

The extensions target Chromium browsers that support Manifest V3 and loading unpacked extensions. Menu names and installation restrictions depend on the browser and your organization’s settings. These builds are not intended for Safari or Firefox.

How do I update an extension?

Unzip the latest version into the same folder, click Reload on its card in chrome://extensions and reload the editor tab. The open page will then receive the new extension code.

Are images and PDFs uploaded to a server?

The web utilities process selected images and PDFs on your device. Internet access is used to load the site and libraries. Other products have network features: for example, the catalogue plugin downloads logos from Trace Logo’s.
