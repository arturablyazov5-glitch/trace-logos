Инструменты для файлов

Небольшие утилиты для работы с файлами прямо в браузере. Всё считается локально — файлы не покидают твоё устройство

Готово Сжать изображение Фото → WebP и безопасная оптимизация SVG. Пакетно, с предпросмотром «до / после». Готово Убрать водяной знак Локальное удаление вотермарков с фото через inpainting. Без загрузки на сервер. Готово Объединить PDF Склей несколько PDF в один файл. Перетаскивай, меняй порядок, скачивай. Готово Обрезать и повернуть фото Кадрируй, поворачивай и выравнивай изображение прямо в браузере. Готово Экран вызова iOS Сгенерируй скриншот входящего звонка iPhone: имя, время, фон, язык кнопок. Расширение Reviews Exporter Chrome-расширение: выгружает все отзывы организации с Яндекс.Карт или продавца на Avito в .md-файл. Устанавливается вручную, без Web Store.
