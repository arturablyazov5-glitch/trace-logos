Tilda Helper FAQ

How do I copy a block ID in Tilda?

Hover over a block in the editor: next to the “Settings” and “Edit block” buttons a badge with the ID, like #rec845210, appears. Click it to copy the ID to the clipboard.

How do I change a block’s Z-index in Tilda?

A Z-index field appears in the block settings. The value is saved in a service T123 block right under it, so you don’t have to edit code by hand.

How do I preview a Tilda page on three screens at once?

Multi-preview opens the published page in three windows, including a 1201 px desktop, and scrolls them in sync. It checks the published version.

Why does multi-preview show old changes?

It opens the published page. Save, publish, then open multi-preview again.

Is there a typography tool for text in Tilda?

Yes, a separate extension — Trace Typograf: it sets non-breaking spaces, dashes and guillemets in text fields in Taptop and Tilda.

Where does the extension work?

In the page, projects and zero editors on tilda.ru and tilda.cc; multi-preview works on tilda.ws.

Why does it need clipboard access?

The clipboardWrite permission is needed to copy IDs, CSS classes, anchors and code.

Is it free, and how do I install it?

Free, pay what you want. The extension is installed from the archive in developer mode (steps are in the “Install in Chrome” block). Tilda Helper is an independent extension, not an official Tilda product. More free tools are in the Tools section.
