01 / npm

From your terminal to assets

A CLI for quick tasks and a library for your scripts. One package: trace-logos.

  • Search English and Russian names, even with the wrong keyboard layout.
  • Download SVG and PNG, or return JSON for scripts and pipes.
  • A current, cached catalog. Node.js 18.17+, ESM, CommonJS and TypeScript types.
npm i trace-logos

Download an SVG or get JSON

sh 
npx trace-logos get telegram --svg --out ./assets
npx trace-logos search telegram --json
CLI flags and a library example

A slug is only unique within its category: alfa, google and monopoly each appear in more than one. When that happens the CLI lists the candidates and you add the category, as in bank/alfa.

--offline uses the cache only, --refresh re-checks the catalog right away. get never overwrites an existing file unless you pass --force.

Library

js 
import { TraceLogos } from 'trace-logos';

const tl = new TraceLogos();
await tl.load();
const [logo] = tl.search('telegram', { limit: 1 });
console.log(logo.name, tl.pageUrl(logo));

ESM and CommonJS, TypeScript types included. Methods: load, search, assetsOf, fetchAsset, pageUrl.

03 / JSON API

The whole catalog in one request

A static logos.json for your website, server or build. No API key or sign-up.

  • Open CORS: read it straight from the browser.
  • Direct links to SVG, PNG and the brand page.
  • Names, tags, categories, ecosystems and logo variants.
Open logos.json ↗
https://trace-logos.ru/logos.json

emoji.json ↗ llms.txt ↗

{
  "name": "Telegram",
  "svgUrl": "https://trace-logos.ru/assets/logos/svgs/telegram.svg",
  "url": "https://trace-logos.ru/logos/social/telegram/"
}

Search in JavaScript

js 
const res = await fetch(
  'https://trace-logos.ru/logos.json'
);
const { logos } = await res.json();
const logo = logos.find(
  ({ name }) => name === 'Telegram'
);
console.log(logo.svgUrl, logo.url);

Some logos have no SVG: check svgUrl and pngUrl. Filter out placeholders with comingSoon: true.

FAQ

Do I need an API key?
No. logos.json is a static file with open CORS, and there is nothing to sign up for. If you read it often, keep your own copy: the trace-logos package, for example, caches the catalog for 10 minutes and revalidates it with an ETag.
How do new logos reach the package and the extension?
No new release needed. Both read the live logos.json from the site, so a brand added to the catalog shows up in search as soon as the local cache expires.
Why does trace-logos get alfa fail?
The slug alfa belongs to both a bank and an insurance company. The CLI lists both and you pick one: bank/alfa or insurance/alfa.
Does the extension work offline?
Search works from the last saved copy of the catalog. Downloading a file that is not cached yet needs a connection.
Can I use the logos in a commercial project?
Logos are trademarks of their owners, and the rules are set by each brand, usually in its brand guidelines. The catalog collects the files in one place but grants no rights to the marks.
