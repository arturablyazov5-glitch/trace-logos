# План: ICNS → максимальное сходство с Icon Composer (Liquid Glass)

> Цель: пользователь скачивает **готовую** иконку, визуально неотличимую от того,
> что рендерит Apple Icon Composer / macOS 26. Не «сырьё в компостер», а финал.

## Контекст / решения
- Бэкап старой реализации: `js/icns.js.bak` (не импортируется, статика грузит только явные модули).
- Что воспроизводим — **статический отрендеренный вид** Liquid Glass (как в Finder/Dock/App Store).
  Живую рефракцию обоев и параллакс-наклон скачанный файл содержать не может в принципе —
  и не должен (ни один .icns этого не содержит). Это НЕ потеря сходства со статикой.
- Эталон для подгонки 1:1 уже в модалке: реальные dock-иконки Finder/App Store
  (`NEIGHBOR_SRCS`, `/assets/icns/dock-*.png`). Крутим параметры, пока центр не сольётся с соседями.

## Источники математики
- Фигура Apple: **figma-squircle** (corner smoothing). Параметры Apple: радиус ≈ **22.37%** стороны,
  smoothing ≈ **0.6**. Порт `getPathParamsForCorner` + 4 draw-функции (точные формулы перенесены).
- Liquid Glass (статика): squircle-маска + стек градиентов (specular/rim/depth) в Canvas 2D.

## Шаги
- [x] **0. Бэкап** `js/icns.js` → `.bak`.
- [x] **Tier-1 багфикс:** убрать типы `icp4`(16)/`icp5`(32) из `ICNS_ENTRIES` — PNG-пейлоады в них
      рендерятся битыми в Finder. Finder интерполирует 16/32 из старших (остаются ic11=32, ic12=64).
- [x] **A. Точная фигура.** Суперэллипс заменён на порт figma-squircle (`cornerParams`/`squircleSvgPath`/`shapeFor`).
      Слайдер «Скругление»: 0%=квадрат → 60%=ТОЧНЫЙ Apple-squircle (r=22.37%, s=0.6) → 100%=круг.
      ✔ верифицировано: кривизна центра 1:1 совпала с реальными dock-иконками Finder/App Store.
- [x] **B. Материал Liquid Glass** (`drawGlass`): купольная подсветка (яркий верх → тёмный низ,
      читается даже на белом), широкий specular-sheen сверху, внутренний rim-light (ярче сверху),
      нижняя тень-кромка. + контактная drop-тень. ✔ на тёмной/цветной плашке глянец совпал с соседями.
- [x] **Плашка/фон.** Контрол «Фон плашки»: свотчи (белый/светло-серый/графит/чёрный) + кастомный пикер.
      Логотип в safe-zone (`GLASS_LOGO_SCALE = 0.66`).
- [x] **Авто-определение** (`looksLikeFullIcon`): готовые иконки (Telegram и пр.) → стекло OFF по умолчанию
      (без «коробки в коробке»); голые глифы/вордмарки → стекло ON. Применяется и к ZIP-бандлу.
- [x] **Дефолты.** `{ radiusPct: 60, paddingPct: 10, shadow: true, glass: true, bg: '#ffffff' }`, glass авто-перебивается детектором.
- [x] **UI-проводка.** Тоггл «Liquid Glass» + ряд свотчей; `isPristine`/`syncControls`/`animateReset` обновлены.
- [x] **Tier-1 багфикс** в энкодере: icp4/icp5 убраны.
- [x] **Верификация.** ✔ модалка, сравнение с dock-иконками, светлая/тёмная плашка, авто-детект Telegram,
      структурная валидация .icns (magic `icns`, длина сходится, 8 типов, все пейлоады — валидный PNG).

## Слои + объём (2.5D, как в Icon Composer) — СДЕЛАНО
- [x] **Разбор SVG на слои** (`splitSvgLayers`): первый full-bleed `<path>` = фон-подложка,
      остальное = передний план. Детект по bbox первого элемента против viewBox.
- [x] **Авто-цвет плашки** из фонового слоя: сплошной цвет (`resolveFill`) ИЛИ градиент
      (рендерим сам слой-подложку — работает для Сбера `fill="url(#a)"`). Свотч «A» (Авто) в UI,
      выбран по умолчанию для слоистых логотипов; `bg: 'auto'`.
- [x] **Объём переднего плана** (`buildFgLayer`): фаска masked к силуэту глифа (верх +свет, низ +тень,
      через `source-atop`) + контактная drop-тень под глифом → глиф «приподнят» над плашкой.
- [x] **Рендер** (`renderIcon(source, size, opts)`): glass on → плашка(авто/цвет) + объёмный передний план
      + стеклянное покрытие; glass off → оригинал как есть. Источник: `prepareSource` → `{full, fg, plate, bgColor, hasLayers, aspect}`.
- [x] ✔ верифицировано: Telegram (сплошной #2AABEE) и Сбер (градиент) — авто-плашка + объёмный глиф
      совпали с dock-иконками; .icns валиден для telegram/sber/youtube/vk (magic, длина, 8 PNG-типов).
- Тюнинг чисел фаски/блика — по эталонным PNG-экспортам из Icon Composer, если пришлёшь.

## Что НЕ делаем сейчас (возможный Tier-C)
- Истинная рефракция кромки логотипа через SVG `feDisplacementMap` (карты Снелла) — «последние 10%».
  Делается отдельно, если глаз будет цепляться после A+B.

## Файлы
- `js/icns.js` — геометрия, материал, дефолты, модалка, энкодер (минус icp4/icp5).
- `css/icns.css` — стили для ряда свотчей фона + тоггла Liquid Glass.
